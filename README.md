# LuxTime - Sitio Web Corporativo

Maqueta web profesional maquetada exclusivamente con **HTML5 y CSS3 nativo**, diseñada para la marca de alta relojería **LuxTime**.

## 📌 Características
- **Código Nativo:** 100% HTML5 y CSS3 sin librerías ni frameworks externos.
- **Diseño Responsive:** Implementación de 3 breakpoints principales (`1200px`, `900px`, `600px`).
- **Carrusel CSS:** Animación `@keyframes` automática para el banner principal.
- **Efecto Hover Zoom:** Implementado en la vista extendida del producto.
- **Validación Visual:** Uso de pseudoclases CSS (`:valid`, `:invalid`) en el formulario de contacto.
- **Flexbox Footer:** Pie de página estructurado estrictamente mediante Flexbox.

## 🛠️ Planificación y Wireframe
La interfaz se estructura mediante una jerarquía basada en tonos oscuros y acentos dorados para transmitir elegancia y exclusividad:
- **Header:** Sticky Navbar para fácil acceso en todas las pantallas.
- **Hero:** Carrusel visual impactante de 3 imágenes.
- **Catálogo:** Grilla flexible que organiza automáticamente 20 modelos.
